# AI Agent Studio

Локальный десктопный AI-ассистент и инженер-программист на базе **Ollama**, **LangChain** и **Flet**. 
Приложение работает полностью локально без отправки кода в облако и оптимизировано даже для ноутбуков с ограниченным объёмом видеопамяти (от 2 ГБ VRAM).

---

## Основные возможности

* **Архитектура Plan-and-Execute:** модель сначала строит пошаговый план действий по строгой JSON-схеме (*Structured Outputs*), а Python-оркестратор детерминированно читает файлы, вносит изменения и проверяет результат.
* **AST-карта репозитория (`Repo-Map`):** автоматическое сканирование `.py`-файлов проекта (классы, сигнатуры методов, функции и глобальные словари/константы) для точной навигации по коду.
* **Точечные патчи и автооткат (`Backtracking`):** перед изменением файлов создаются резервные снимки. Если синтаксис (`ast.parse`) или тестовый скрипт (`verify`) выдают ошибку, агент пытается исправить код по логу ошибки или откатывает файл в исходное состояние.
* **Долговременная память на SQLite:** сохранение истории диалогов по проектам, автоматическое сжатие контекста (*Rolling Summary*) и локальный полнотекстовый поиск (`FTS5`) по документациям в папке `~/ai_docs`.
* **Роутинг моделей в UI:** быстрое переключение между лёгким режимом (`3B` для GPU от 2 ГБ VRAM) и сложным режимом (`7B` для CPU + RAM).

---

## Системные требования

* **ОС:** Linux (Ubuntu 22.04 / 24.04), Windows 10/11 или macOS.
* **Python:** версия **3.10** или выше.
* **Железо:** 
  * Минимум: 8–16 ГБ RAM и GPU от 2 ГБ VRAM (для модели `3B`).
  * Рекомендуется: 16+ ГБ RAM или GPU от 6–8 ГБ VRAM (для комфортной работы модели `7B`).

## Шаг 1. Установка Ollama и загрузка моделей

1. Установите **Ollama**:
   * **Linux (Ubuntu):**
     ```bash
     curl -fsSL https://ollama.com/install.sh | sh
     ```
   * **Windows / macOS:** скачайте установщик с официального сайта [ollama.com](https://ollama.com).

2. Загрузите основную быструю модель (обязательно, ~1.9 ГБ):
   ```bash
   ollama pull qwen2.5-coder:3b
   ```

3. *(Опционально)* Загрузите более мощную модель для сложного рефакторинга (~4.7 ГБ):
   ```bash
   ollama pull qwen2.5-coder:7b
   ```

> **Проверка:** убедитесь, что фоновая служба Ollama запущена (по умолчанию доступна по адресу `http://localhost:11434`).

---

## Шаг 2. Настройка окружения Python

### 1. Системные зависимости (только для Linux / Ubuntu)
Для корректной работы графического окна Flet в Ubuntu установите библиотеку GTK3 и модуль виртуальных окружений:
```bash
sudo apt update
sudo apt install -y python3-pip python3-venv libgtk-3-dev
```

### 2. Создание виртуального окружения и установка библиотек
Откройте терминал в корневой папке проекта (рядом с папкой `workspace`) и выполните команды:

**Для Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install flet langchain-ollama langchain-core pydantic
```

**Для Windows (PowerShell):**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install --upgrade pip
pip install flet langchain-ollama langchain-core pydantic
```

---

## Шаг 3. Запуск приложения

При активном виртуальном окружении (`.venv`) запустите главный файл:

```bash
python3 workspace/main.py
```

При первом запуске программа автоматически создаст:
* базу данных истории чатов `workspace/agent_memory.db`;
* рабочую директорию по умолчанию `~/my_project`;
* папку для локальной документации `~/ai_docs`.

---

## Краткое руководство по работе

1. **Выбор рабочего проекта:** нажмите на иконку папки в левом верхнем углу боковой панели (`Sidebar`), чтобы указать директорию с вашим кодом. Агент изолирован внутри выбранной папки и не изменяет файлы за её пределами.
2. **Постановка задач по коду:** описывайте задачу конкретно, указывая целевые файлы и команду проверки, например:
   > *«Изучи items.py и crafting.py, исправь списание ресурсов при отмене крафта и проверь решение командой `python3 run_test.py`».*
3. **База знаний (`~/ai_docs`):** положите любые `.md` или `.txt` файлы (документацию библиотек, шпаргалки, заметки) в папку `~/ai_docs` — при перезапуске приложения они проиндексируются в SQLite FTS5, и агент сможет искать по ним ответы без нагрузки на видеопамять.
4. **Переключение моделей:** в нижней части левой панели можно переключаться между профилями **Быстрый (3B)** и **Сложный (7B)** без перезапуска программы.

## Структура проекта

```text
├── README.md                 # Инструкция по установке и запуску
└── workspace/
    ├── main.py               # Точка входа Flet и сборка интерфейса
    ├── config.py             # Настройки моделей, лимиты контекста и промпты
    ├── core/
    │   ├── database.py       # Работа с SQLite (проекты, чаты, summary, FTS5)
    │   ├── model.py          # Взаимодействие с Ollama, Structured Outputs и стриминг
    │   └── orchestrator.py   # Исполнение плана, проверка AST и автооткат
    ├── tools/
    │   ├── code_tools.py     # AST-карта репозитория, патчи, чтение/запись и тесты
    │   └── doc_search.py     # Полнотекстовый поиск по локальным документам
    └── ui/
        ├── sidebar.py        # Боковая панель (выбор папки, список чатов, выбор модели)
        └── chat_view.py      # Окно чата с поддержкой фоновой генерации и кнопкой «Стоп»
```
